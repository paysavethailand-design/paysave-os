# public

Publicly accessible static assets.

- `images/` — optimized public images.
- `icons/` — application icons and approved SVG assets.
- `fonts/` — licensed web fonts.
- `locales/th/` — Thai translation resources.
- `locales/en/` — English translation resources.

Anything placed here may be publicly downloadable. Never store PII, evidence, contracts, API keys, or internal documents in this directory.
